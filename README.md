# Drug Side Effect Prediction

A Multi-Layer Perceptron (MLP) is used in this project to predict potential side effects linked to specific medication ingredients.

The OnSIDES dataset is used by the model to predict 497 adverse-effect categories using 2048-bit Morgan molecular fingerprints created with RDKit.

## Main Program

predict.py

This is the main program used to make predictions.

## Features

- Predicts potential side effects of medicine ingredients.
- Uses chemical molecular fingerprints.
- it shows the molecular formula and chemical structure
- Shows the top 10 predicted side effects and their prediction scores.

## Technologies Used

- Python
- PyTorch
- RDKit
- Pandas
- NumPy
- Scikit-learn

## Disclaimer

Predictions are computational estimates and should not be interpreted as clinically confirmed side effects or medical advice.
